<h1>PREVISÃO DO TEMPO</h1>
<p>Trata-se de aplicação de consulta de previsão do tempo utilizando a WeatherAPI (www.weatherapi.com). O aplicativo possui o campo de busca com autocomplete, além de fornecer as condições do tempo atual e a previsão do tempo para os próximos dois dias.</p>

## Tecnologias utilizadas
<li>Vite</li>
<li>TypeScript</li>

## Bibliotecas utilizadas
<li>Prime React</li>
<li>Prime Icons</li>
<li>Prime Flex</li>

## Instruções
Antes de começar, você precisa ter as seguintes ferramentas instaladas:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (recomenda-se a versão LTS)
- [npm](https://www.npmjs.com/) ou [Yarn](https://yarnpkg.com/)

### 🚀 Como executar o projeto

Siga os passos abaixo para clonar e rodar o projeto localmente:

```bash

# Clone o repositório
git clone https://github.com/lucastnsoares/weather-forecast.git

# Acesse o diretório do projeto
cd weather-forecast

# Instale as dependências
npm install
# ou
yarn

# Crie um arquivo .env, conforme arquivo .env.example, na pasta raiz do seu projeto, inserindo sua chave de API na variável VITE_API_BASE_URL.
VITE_API_KEY=
VITE_API_BASE_URL="https://api.weatherapi.com/v1/"

# Execute o projeto em modo de desenvolvimento
npm run dev
# ou
yarn dev
